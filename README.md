# lightmix_temperaments

This zig package is for my library, [lightmix](https://github.com/haruki7049/lightmix). This package provides some temperaments for it. You can use this to define scale on your code.

However, this package doesn't have a lightmix dependency, so you can use this package for any other zig programs.

## Zig version

Zig 0.15.2
